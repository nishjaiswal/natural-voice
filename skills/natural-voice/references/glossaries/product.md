# Product terms

| When they say something like | Term |
|---|---|
| the steps and how many people get through each | funnel |
| where people gave up | drop-off / abandonment |
| people came back | retention |
| people stopped using it | churn |
| the first time someone uses it | onboarding / first-run experience |
| the moment they get why it's useful | activation / moment of value |
| the one number we cared about most | the main metric (north-star metric only if they call it that) |
| we tried two versions to see which did better | ask: a live split test on real traffic (A/B test), or two versions shown to a few people (compared two versions)? |
| we released it to some people first | staged rollout / beta |
| switched it on for some users only | feature flag |
| the smallest version we could ship | MVP / first release |
| what people are really trying to get done | the job to be done / user goal |
| deciding what to build first | prioritisation |
| the plan for the next few months | roadmap |
| things we chose not to do | out of scope / trade-offs |
| problems we already know about | known issues |
| what it costs us vs what we get | cost versus benefit (ROI only if they measured it) |
| the people who have a say | stakeholders |
| rules we had to follow | regulatory constraints / compliance |
| how we'll know it worked | success criteria |
