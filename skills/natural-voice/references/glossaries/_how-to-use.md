# How to use the term lists

Each list maps how people *describe* something when talking to the term a senior person in that field would *write*. Use a term only when it means exactly what the person described. If two terms could fit, ask. Never swap in a term that implies a more formal method, a bigger sample or a measured result than the person described. Prefer the plainer term when both are accurate: precise is better than jargon-heavy. The person's own *My terms* in the voice file always win over these lists.

Contributions welcome: add rows to a list, or add a new list for another field.
