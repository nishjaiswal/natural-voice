# General terms (for any field)

| When they say something like | Write |
|---|---|
| it was all over the place | inconsistent |
| people just gave up | people abandoned it / dropped off |
| I sort of led it | I led it (if they did), or I contributed to it (if they didn't): ask |
| we kind of tested it | we tested it with <n> people: ask how many |
| it worked way better | it improved <what> from <x> to <y>: ask for the numbers |
| a bunch of | several / <the actual number, if they gave one; otherwise keep it vague or ask> |
| stuff | <the actual things> |
| super important | important |
| basically | (cut) |
| at the end of the day | (cut) |
