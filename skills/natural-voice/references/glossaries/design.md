# Design terms

| When they say something like | Term |
|---|---|
| a huge board you can pan around, click and drag on | interactive canvas (infinite canvas if it has no edges) |
| the frame or page you design on | artboard / frame |
| boxes that each hold a bit of content | cards |
| the bar at the bottom with the main tabs | bottom navigation / tab bar |
| the menu that slides in from the side | navigation drawer / side sheet |
| the panel that slides up from the bottom | bottom sheet |
| the popup in the middle you have to deal with | modal / dialog |
| the round floating button | floating action button |
| small rounded tags you tap to filter | filter chips |
| the row you scroll sideways | horizontal carousel |
| the line that shows which step you're on | progress indicator / stepper |
| splitting a long form into pages | multi-step form |
| putting related things together | grouping / chunking |
| making the most important thing look most important | visual hierarchy |
| how everything is organised and named | information architecture |
| the same layout working on phone and desktop | responsive layout |
| hiding the advanced stuff until it's needed | progressive disclosure |
| sections that open and close | accordion |
| the screen before there's any content | empty state |
| the screen saying it worked | success state / confirmation screen |
| grey placeholder boxes while it loads | skeleton screen / loading state |
| it checks your answer as you type | inline validation |
| it remembers where you were | saved progress / auto-save |
| a little hint next to the field | helper text |
| the right keyboard pops up for each field | input types / contextual keyboards |
| bigger buttons so you don't miss them | larger touch targets |
| people tapping again and again in frustration | rage taps / rage clicks |
| the small animation when you tap | micro-interaction |
| the message that pops up and disappears | toast / snackbar |
| the main button | primary action |
| already filled in with a sensible answer | sensible default |
| a quick clickable version | prototype |
| rough boxes and lines | wireframes |
| the shared buttons, colours and rules | design system / component library |
| named colour and spacing values | design tokens |
| the flowchart of screens and choices | user flow / task flow |
| the map of everything someone goes through | journey map |
| watched recordings of people using it | session recordings |
| sat with people and watched them try it | usability sessions (moderated sessions only if they ran them as such; ask) |
| looked at what other apps do | competitor review |
| where people gave up | drop-off |
| usable by everyone, including with a screen reader | accessible / accessibility |
